# Landing Page - VidaPlena SpA
Creación de Web para una empresa de servicios en bienestar y salud integral
## Descripción del Proyecto
Este proyecto es una Landing Page estática desarrollada para "VidaPlena SpA", una empresa emergente de servicios de bienestar y salud integral. El objetivo es captar clientes potenciales y comunicar los servicios de terapia física, nutrición y salud mental de la marca.

## Tecnologías Utilizadas
* HTML5 (Estructura semántica)
* CSS3 (Variables, Flexbox, Grid, Responsive Design)
* Git y GitHub (Control de versiones)

## Instrucciones de Uso
1. Clonar el repositorio.
2. Abrir el archivo `index.html` en un navegador web.

## Uso de IA
En cumplimiento con las instrucciones de la evaluación, declaro el uso responsable de herramientas de Inteligencia Artificial (IA) generativa como apoyo durante el desarrollo de este proyecto:
* **Herramienta utilizada:** Gemini.
* **Uso específico:** Asistencia para estructurar el código HTML5 con etiquetas semánticas y crear la hoja de estilos CSS3 cumpliendo con Responsive Design.
* **Prompt principal:** Se proporcionó la pauta de evaluación y se solicitó un paso a paso estructurado para guiar la codificación.
* **Adaptación:** El código entregado fue revisado, modificado e integrado paso a paso, asegurando que los enlaces y rutas funcionaran correctamente en mi entorno local.
