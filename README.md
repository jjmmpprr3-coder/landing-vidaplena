# landing-vidaplena

Landing page para **VidaPlena SpA**, empresa de servicios de bienestar y salud integral.

## Objetivo

Esta web permite:

- Captar clientes potenciales con un mensaje claro de valor.
- Comunicar los servicios principales de VidaPlena.
- Facilitar el contacto con el equipo mediante formulario, correo y teléfono.

## Cómo visualizar

Al ser un sitio estático, puedes abrir `/tmp/workspace/jjmmpprr3-coder/landing-vidaplena/index.html` en tu navegador.
